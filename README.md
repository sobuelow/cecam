3) Try out the [pKasso webserver](https://tools.bindresearch.org/pkasso) with some of your favorite molecules. More information on SMILES codes is on [wikipedia](https://en.wikipedia.org/wiki/Simplified_Molecular_Input_Line_Entry_System).
